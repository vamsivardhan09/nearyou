## ✨ What is CelebrateNear?

**CelebrateNear** is built on one belief: *the most valuable gift you can give someone is the proof that they are remembered.*

We live in a world where the people who shaped us — mothers, fathers, partners, friends — often never truly hear how much they mean to us. CelebrateNear exists to fix that.

It is an **emotional gifting and memory preservation platform** where you can:

- 🎁 **Create surprise emotional experiences** for birthdays, anniversaries, milestones, or just because
- 📖 **Build cinematic memory story pages** organized by relationship (Mom, Dad, Partner, Friends, Family)
- 🎙️ **Collect voice notes, videos, photos, and messages** from anyone who loves the recipient
- 🌟 **Present it all** as a beautifully designed, emotionally resonant digital experience
- 💌 **Share privately or publicly** as a permanent emotional legacy

> *"It's not a card. It's not a gift. It's proof that someone's life changed yours."*

## 🚀 Quick Start

### Prerequisites

Make sure you have the following installed:

```bash
node --version    # v18+ required
npm --version     # v9+ or use pnpm
git --version
```

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/celebratenear.git
cd celebratenear
```

### 2. Install Dependencies

```bash
# Using npm
npm install

# Using pnpm (recommended)
pnpm install
```

### 3. Configure Environment Variables

```bash
cp .env.local.example .env.local
```

Fill in your credentials (see [Environment Variables](#-environment-variables) below).

### 4. Set Up Supabase

Run the database schema in your Supabase project (see [Supabase Setup](#-supabase-setup)).

### 5. Start the Development Server

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🔐 Supabase Setup

### Step 1 — Create a Supabase Project

1. Go to [supabase.com](https://supabase.com) and sign in
2. Click **New Project** and fill in project details
3. Wait for the project to initialize (~2 minutes)

### Step 2 — Run the Database Schema

In your Supabase dashboard, go to **SQL Editor** and run the full contents of `schema.sql`:

```sql
-- Profiles table (linked to Supabase Auth)
CREATE TABLE IF NOT EXISTS public.profiles (
  id UUID REFERENCES auth.users(id) ON DELETE CASCADE PRIMARY KEY,
  full_name TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);

-- Events table
CREATE TABLE IF NOT EXISTS public.events (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  creator_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE,
  event_type TEXT NOT NULL,
  receiver_name TEXT NOT NULL,
  receiver_email TEXT,
  event_date DATE NOT NULL,
  story TEXT,
  theme_config JSONB DEFAULT '{}'::jsonb,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);

-- Memories table
CREATE TABLE IF NOT EXISTS public.memories (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  event_id UUID REFERENCES public.events(id) ON DELETE CASCADE,
  contributor_name TEXT NOT NULL,
  media_type TEXT NOT NULL CHECK (media_type IN ('text', 'image', 'video', 'voice')),
  media_url TEXT,
  text_content TEXT,
  is_approved BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);

-- Important dates
CREATE TABLE IF NOT EXISTS public.important_dates (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  date DATE NOT NULL,
  type TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);
```

> ⚠️ **Full RLS policies are included in `schema.sql`** — run the complete file, not just the snippet above.

### Step 3 — Enable Authentication

1. In Supabase dashboard → **Authentication** → **Providers**
2. Enable **Email** provider
3. (Optional) Enable **Google OAuth** for social login
4. Under **URL Configuration**, set your site URL:
   - Development: `http://localhost:5173`
   - Production: `https://your-domain.com`

### Step 4 — Configure Storage (for media uploads)

1. Go to **Storage** → **Create Bucket**
2. Create a bucket named `memories`
3. Set it to **Public**
4. Add a storage policy to allow authenticated uploads:

```sql
-- Allow authenticated users to upload
CREATE POLICY "Authenticated users can upload"
ON storage.objects FOR INSERT
TO authenticated
WITH CHECK (bucket_id = 'memories');

-- Allow public read
CREATE POLICY "Public can view memories"
ON storage.objects FOR SELECT
TO public
USING (bucket_id = 'memories');
```

### Step 5 — Get Your API Keys

In Supabase dashboard → **Settings** → **API**:

- Copy your **Project URL**
- Copy your **anon/public** key

## 🌐 Environment Variables

Create a `.env.local` file in the project root:

```env

VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

# ─── Cloudinary (for media uploads) ─────────────────────────
VITE_CLOUDINARY_CLOUD_NAME=your-cloud-name

VITE_VAPI_PUBLIC_KEY=your-vapi-public-key
VITE_VAPI_ASSISTANT_ID=your-vapi-assistant-id
```

> 🔒 **Never commit `.env.local` to version control.** It is listed in `.gitignore` by default.

## 🎙️ Vapi Integration (AI Voice Calls)

CelebrateNear supports **AI-powered surprise voice calls** delivered by a warm, emotionally tuned voice assistant.

### Setup

1. Create an account at [vapi.ai](https://vapi.ai)
2. Create an **Assistant** with this system prompt:

```
You are a warm, emotionally intelligent celebration concierge for CelebrateNear.
Your job is to deliver personalized surprise messages on behalf of a loved one.
Speak softly, warmly, and with genuine emotional depth.
Use the recipient's name naturally. Pause for emotional moments.
Read the collected memories and messages with heartfelt delivery.
```

3. Configure the assistant voice to **Aria** or **Emma** (ElevenLabs voices recommended)
4. Add your `VITE_VAPI_PUBLIC_KEY` and `VITE_VAPI_ASSISTANT_ID` to `.env.local`

### Usage in Code

```typescript
import Vapi from '@vapi-ai/web';

const vapi = new Vapi(import.meta.env.VITE_VAPI_PUBLIC_KEY);

// Start a surprise call
await vapi.start(import.meta.env.VITE_VAPI_ASSISTANT_ID, {
  variableValues: {
    recipientName: 'Ananya',
    senderName: 'Rahul',
    occasion: 'Birthday',
    personalMessage: 'You have always been my anchor...',
  },
});
```

## 📦 Deployment

### Deploy to Vercel (Recommended)

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Set environment variables via Vercel dashboard or CLI
vercel env add VITE_SUPABASE_URL
vercel env add VITE_SUPABASE_ANON_KEY
vercel env add VITE_CLOUDINARY_CLOUD_NAME
vercel env add VITE_CLOUDINARY_UPLOAD_PRESET
```

**Or connect your GitHub repo directly:**

1. Push your code to GitHub
2. Import the repo at [vercel.com/new](https://vercel.com/new)
3. Add environment variables in **Settings → Environment Variables**
4. Deploy — Vercel auto-builds on every push to `main`

### Deploy to Netlify

```bash
# Build
npm run build

# Deploy dist/ folder
npx netlify-cli deploy --dir=dist --prod
```

Add environment variables in **Netlify → Site Settings → Environment Variables**.

### Manual Build

```bash
# Production build
npm run build

# Preview the build locally
npx vite preview
```

The `dist/` folder contains the static bundle — deploy it to any static host (Cloudflare Pages, GitHub Pages, AWS S3, Firebase Hosting).
